## Reading

- **US, EU, international register:** no conflicting mark found for the name or its spellings.
- **India:** "Saarathi" and "Sarathi" (charioteer, guide) are common in Indian brand names. No plain SAARATHI mark covers
  software, but compound marks containing the word do (notably VIDYASAARATHI, NSDL, class 42). An open-source developer
  tool with a distinct context is a different setting, but this is the main residual risk.
- **Confusion risk:** the PyPI project `sarathi` is also a CLI coding assistant.
- Not checked: unregistered (common-law) use, pending applications not yet in TMview, and registers outside the TMview
  network. The official IP India public search needs a CAPTCHA and was not used.
- Before any commercial use or a trademark filing of your own, have a trademark attorney run a formal search.
