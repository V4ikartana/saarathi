# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, give and accept constructive feedback, and focus on what is
best for the community. Harassment and personal attacks are not tolerated.
